# Merlin 的句法树形图生成器

[English](README.md)

Merlin 的句法树形图生成器是一个面向语言学研究者、句法课教师和学生的免费在线工具。它可以把括号表达式转换为可编辑的句法树形图，并支持移位线、空位置、三角形 roof、自由注释、手动布局和适合论文或教学材料的多种导出格式。

- 在线使用：<https://ailinguistics.cloud/mss>
- 当前程序版本：**0.2.2**
- 开发者：**Merlin X. D. Yang**
- 开源许可证：[MIT](LICENSE)

## 当前功能

### 树形图编辑

- 输入方括号或圆括号表达式后即时生成预览。
- 支持 `_i`、`_j`、`_k` 等可见下标，以及 `_z1`、`_z2` 等隐藏移位下标。
- 每条移位线可以独立设置实线/虚线、颜色、显示状态和手动几何位置。
- 可以拖动标签、树枝、移位线和三角形 roof。
- 可以选中任意树枝将其隐藏，并在控制栏中恢复。
- 支持输入撤销/恢复、按钮与触控板双指缩放、注释颜色、自由注释和三点弧形曲线。
- 支持空 terminal、真正的空节点、带索引的空移位位置和完全静默节点。

### 导出

- SVG。
- 透明背景 PNG 和白色背景 PNG。
- **Forest LaTeX**：保留可以继续编辑的树形结构。
- **视觉 TikZ LaTeX**：保留手动位置、隐藏树枝、线型、颜色、注释和曲线。
- 支持中日韩文字的 XeLaTeX 输出。

### 账户、留言和管理员后台

- 无需注册即可使用的游客模式。
- 电子邮件注册，以及可选的 Google/GitHub OAuth 配置。
- 登录用户可以保留最近 20 条树形图生成记录。
- 公开 Feedback BBS：任何人都可以查看，只有注册用户可以留言。
- 首条留言审核、仅管理员正式回复、编辑、批准、移入回收站、恢复和永久删除。
- 重复留言、外部链接数量、提交间隔、每日留言、注册和登录频率限制。
- 独立管理员后台，显示全部历史用户、留言、国家、机构和访问记录。
- 所有大型列表支持每页显示 20、40 或 100 条。
- 程序界面支持英语、简体中文、西班牙语、日语和韩语；新安装默认启用中文、英语和西班牙语。

## 语法说明

| 语法 | 示例 | 效果 |
|---|---|---|
| `[XP child child]` | `[TP John [T' T VP]]` | 基本节点。第一个项目是节点标签，其余项目是子节点。 |
| `(...)` | `(TP John (VP ...))` | 圆括号也可以表示树结构。 |
| `A\|B\|C` | `T0\|\[+PST\]\|\[+3SG\]` | 同一节点内换行。作为文字的方括号必须写成 `\[` 和 `\]`。 |
| `_i`、`_j`、`_k` | `John_i` | 显示斜体下标；相同下标自动生成移位线。 |
| `_z1`、`_z2` | `thought_z1 ... is_z2+phi` | 隐藏移位下标；不显示下标，但仍参与移位线匹配。 |
| `t_i` / `trace_i` | `t_i` | 移位对应的 trace 或空位标签。 |
| `=word=` | `=read=_k` | 删除线；旧写法 `-word-` 仍然兼容。 |
| `*word*` | `*where*_i` | 斜体。 |
| `=*word*=` | `=*read*=_k` | 斜体加删除线。 |
| `@word@` | `@he will go *where*@_i` | 空心字；内部可以继续使用斜体。 |
| `"text with spaces"` | `"(head)"` / `"New York"` | 把空格或括号内容保留为一个文字标签。 |
| `v0` / `X0` | `v0\|read_k`、`C0` | 把 0 显示为上标。 |
| `X1`、`X2` | `DP1` | 把末尾非零数字显示为下标。 |
| `alpha`、`beta`、`phi` | `alpha_i`、`phi+thought_z1` | 希腊字母快捷输入；也支持 theta、lambda、omega 等。 |
| `[^TP words]` | `[^TP @he will go *where*@_i]` | 三角形/roof 节点。 |
| `@empty` | `[TP @empty T']` | 保留空 terminal 的树枝，但不显示文字。 |
| `[]`、`[_i]`、`[_z2]` | `[TP [] [_i] [_z2]]` | 创建真正的空节点或带索引的空移位位置。 |
| `@silent` | `[C @silent]` | 完全隐藏标签，也不绘制通向它的树枝。 |

示例：

```text
[CP Which-book_i [C' C0|did [TP John_j [T' T0|\[+PST\] [vP =John=_j [v' v0|read_k [VP =read=_k t_i]]]]]]]
```

## 本地运行

环境要求：

- PHP 8.1 或更高版本。
- PDO SQLite、mbstring 和 fileinfo 扩展。
- 现代浏览器。

```bash
git clone https://github.com/merlinxdyang/SyntaxTreeStudio.git
cd SyntaxTreeStudio
php -S 127.0.0.1:8082
```

打开：

- 首页：<http://127.0.0.1:8082/index.php>
- Workspace：<http://127.0.0.1:8082/index.php?action=workspace>
- 管理员后台：<http://127.0.0.1:8082/admin/admin.php>

第一次访问时，程序会自动创建 `data/syntree.sqlite`。运行时数据库和用户上传的反馈图片不会进入 Git 版本控制。

新数据库默认建立的独立管理员账号为：

```text
用户名：admin
密码：Admin123456
```

在本地开发以外的环境开放网站前，必须立即进入管理员后台的 Security 页面修改密码。

## 项目结构

| 路径 | 用途 |
|---|---|
| `index.php` | 公共路由、首页、登录注册、Workspace、帮助、Feedback BBS 和多语言内容。 |
| `admin/admin.php` | 独立私有管理员后台和 BBS 管理。 |
| `app.js` | 解析器、布局引擎、编辑交互、移位线和 SVG/PNG/LaTeX 导出。 |
| `feedback.js` | 安全的 Feedback BBS Markdown 工具栏和附件界面。 |
| `landing.js` | 支付宝赞助二维码浮窗交互。 |
| `style.css` | 首页、Workspace、BBS 和管理员后台的响应式样式。 |
| `src/db.php` | SQLite 结构、迁移、查询、计数器、频率限制和历史保留。 |
| `src/auth.php` | 注册、电子邮件登录、会话和登录频率限制。 |
| `src/oauth.php` | 可选的 Google 和 GitHub OAuth 流程。 |
| `tests/` | 不依赖外部测试框架的 PHP 回归测试。 |
